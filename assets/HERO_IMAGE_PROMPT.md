# Make a true 3D-quality hero picture (2 minutes)

The app shows `assets/hero.png` (or `hero.jpg`) automatically if the file exists, so no code changes are needed. Until then it uses the built-in illustration (`assets/clinic_team.svg`).

## Steps
1. Paste the prompt below into an image generator (for example ChatGPT image generation, Google Gemini, Microsoft Designer, Adobe Firefly or Midjourney).
2. Ask for a **wide banner (about 2:1)**. If it comes out square, ask it to "extend to a wide 2:1 banner" or crop it.
3. Save the image as `assets/hero.png` in the project folder (replace the name exactly).
4. Reload the app: `streamlit run app.py`.

## Prompt
> A wide cinematic banner, ultra-detailed 3D render, Pixar-quality realistic lighting. A friendly veterinarian stands in the center, facing the camera, smiling, wearing a white coat and a stethoscope. Two veterinary assistants in teal scrubs stand slightly behind on the left and right. In the foreground: a Rottweiler, a Siberian husky with blue eyes, an orange tabby cat, a white cat, a green ball python coiled on a table, and a small turtle. Bright, modern veterinary clinic interior in blue, green and turquoise tones, soft studio lighting, gentle depth of field, clean and professional, high detail, 8k. No text, no logos, no watermark.

## Tips
- To change the look, replace "Pixar-quality" with "photorealistic" for a photo style.
- Keep the people and animals in the middle and lower part of the picture, so the page text above it stays readable.
- Do not use a photo of a real person without permission.
